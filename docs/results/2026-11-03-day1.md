## Problems found (to fix next)

1. **Interpreter didn't know scene-type codes** — it saw only the Japanese label, so rules scoped to a type were scoped to `T1`
   by guess (e.g. K-006 「白樺製菓への季節のあいさつは手紙で」 learned on a T6 greeting, scoped T1).
2. **Over-general rule broke an earlier one** — K-013 「白樺製菓への正式な連絡は窓口宛て（社長に用がある場合も同じ）」, learned on a
   succession scene, contradicts the seasonal letter to the president → E02 regressed. Needs the planned conflict check
   (「以前は〇〇でしたが、変わりましたか？」) and a regression test on past ○.
3. **History never captured where the apprentice is never wrong** — explicit constraints (Teams only, designated format) are followed
   from the start, so no correction, no "why?", no history: Q01/Q06 (港北) and Q04/Q05 (生協) stay "unknown".
4. **Company-wide rules don't generalize** — E08/E12/E18 stay △ (precedent, heads-up in busy season, "happy to explain"): rules are
   learned per client and never widened.
