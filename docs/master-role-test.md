# 師匠役テストの手順（所要30分）

> **実施済み（11/4、D-059）。** 結果は `docs/results/master-role-test-2026-11-04.json`。下の手順3（同じ作法を文章で書く）は
> 行っていません。作者にはこの会社と取引した経験がなく、書き起こす元がないためです。書く時間との比較はしていません。

作者（Kento）が師匠役になり、**架空の場面**で帳場を操作して時間を測るテストです。実際の取引先や現場では試しません。
（11/3 までの名前は「実地テスト」でした。誤解を避けるために改名しました。D-046）
**内部では `field` という名前のままです**（環境変数 `KOKOROE_FIELD`、モード名 `field`、`npm run field:save`、`src/server/field.ts`）。壊さないために変えていません。

Kento が師匠（篠原）役で、20場面に ○△× と一言を付け、そのあと同じ作法を5つ文章で書きます。比べるのは、**○△×で直す時間と文章で書く時間、
出てきた作法の数**です（D-031、D-041）。結果は一人の人が測ったものとして報告します。データはすべて架空です。

リハーサル（2026-11-03、Claude が Playwright で通しました）: ライブで20枚 → 直し3件（3件とも心得帳に書かれ、確かめ稽古と回帰の確認まで
済み）→ 文章5件 → まとめ。費用は約 $0.18（30回の呼び出し）。自動操作で76秒かかりました。人が読んで判断すると、20枚で約15分の見込みです。
スクリーンショットは `docs/screens/field-rehearsal-*.png` です。

## 0. 準備（2分）
- `git pull` と `npm ci` をして、`.env.local` に開発用キーがあることを確かめます（値は表示しないこと）。
- ほかに開発用サーバーが動いていないことを確かめます（Next.js 16 は、1つのプロジェクトにつき開発用サーバーを1つしか動かせません）。

## 1. 起動（ライブ、自分の PC からだけ開ける形）
```bash
KOKOROE_FIELD=1 KOKOROE_LIVE=1 KOKOROE_SESSION_CALLS=300 KOKOROE_IP_CALLS_PER_HOUR=600 \
  npm run dev -- --hostname 127.0.0.1 --port 3100
```
- `KOKOROE_FIELD=1`: 師匠役テストの入口を出します（公開版では出しません）。
- `KOKOROE_LIVE=1`: 案と解釈を Claude がその場で作ります。
- 呼び出し回数の上限を上げます（1セッション40回の既定では、20枚の途中で記録済みのデータに切り替わってしまうため）。1日の費用の上限は既定の $5 のままで十分です。

http://127.0.0.1:3100 を開き、「**師匠役テストを始める（作者用・所要時間を記録します）**」を押します。
**途中でトップから「始める」を押し直さないでください。** 新しいセッションになり、記録がやり直しになります（ページの再読み込みは大丈夫です）。

## 2. 20場面に印を付ける（約15分）
1枚ずつ、場面と弟子（橙丸）の案（表の連絡・裏の一言・時期・後日のあいさつ…）を読み、**○ よい／△ 条件つき／× ちがう** を選びます。
直したいことがあれば一言を添えて（なくても可）「記録する」を押します。次の案はすぐ出ます。△・× の読み取りは、右の「裏での作業」で進みます。

右の欄で求められることがあれば、手が空いたときに答えます（待たずに次の札へ進んでかまいません）。
- **どの意味でしたか**: 読み方の候補から合うものを1つ選びます。「どれでもない」を選ぶと2巡目の候補が出ます。
- **わけを一言**: 心得が書かれたあとに1回だけ聞かれます。答えても飛ばしてもかまいません。
- **確かめ／回帰の確認**: 直した場面と、以前 ○ を付けた場面を新しい心得で解き直した案に、○△× を付けます。

## 3. 同じ作法を文章で書く（約10分）
「同じ作法を文章で書く」（/choba/write）へ進み、後任に渡すメモのつもりで書きます。各問いが表示されてから「記録する」を押すまでの時間を測ります。
1. T05: 丸新酒造に新しい提案をするとき、誰にどう話を通すか
2. T15: 浜風運輸に納期の遅れを伝えるとき、いつ・誰に・どう伝えるか
3. T21: まちなか生協に見積りを出すとき、気をつけること
4. T27: 大河原建材の社長に新しい提案をするとき、どう進めるか
5. T09: 白樺製菓の2〜3月に見積りの依頼が来たとき、どう対応するか

## 4. 結果の出し方（3分）
1. 「所要時間のまとめ」（/choba/report）を開いて、スクリーンショットを撮ります（操作ごとの中央値。確かめ・回帰の確認のタップは、印を付ける時間とは別の行に出ます）。
2. 結果をリポジトリに保存します（API は呼びません）。
   ```bash
   npm run -s field:save            # → docs/results/master-role-test-<実施日>.json（書いた文章を含む）
   npm run -s field:save -- --no-text   # 文章を残したくない場合（時間と件数だけ）
   ```
3. サーバーを止めます（Ctrl-C）。
4. 保存した JSON の `proseEtiquetteCount` に、5つの文章に出てきた作法の数を数えて入れます。心得帳に書かれた数（`rulesLearned`）と比べるためです。
   数え方: 「誰に・いつ・どの手段で・何を先に」のうち、別々に守れる決まりごとを1つと数えます。
5. Claude に「師匠役テストの結果を記録して」と伝えてください。README と稽古の記録に、一人の人が測った結果として載せます。

## うまくいかないとき
- 札の上に「本日のお試し上限」などの案内が出た → 呼び出し回数の上限に当たっています。手順1の環境変数が付いているかを確かめ、サーバーを起動し直してください（記録はそのまま残ります）。
- 案が出ずに読み込みが続く → 1回だけ再読み込みします。それでも出なければ、サーバーのログの最後の数行を Claude に見せてください。
