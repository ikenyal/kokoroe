# Judging criteria (Built with Claude: Japan 2026)

The criteria shown at the kickoff, as Kento passed them on (11/5). Used by the `judge-critic` subagent
(`.claude/agents/judge-critic.md`) to read the submission as a judge would. The weights are the organisers'.

## インパクト 30%
- 自分の仕事や日本の現場から出発しているか
- その世界にいた人だから見えた「足りないもの」があるか
- 誰が、どんな場面で、どれくらい困っているか
- ハッカソン後も、誰がどんな場面で使い続けるか

## デモ 25%
- 冒頭で「誰の、どんな課題を、どう解決するか」が明確か
- 前提知識のない人が、操作の流れで価値が分かるか
- 最後まで見たくなるか

## Claude の活用 25%
- 基本を超えた使い方
- Claude Code を開発の中心に据えて、何が可能になったか
- Skills・サブエージェント・MCP・フックなどを、目的に応じて使い分けているか

## 深さと実行力 20%
- 試行錯誤を重ねて磨いた跡
- 設計と実装の丁寧さ
- 困っている人が、安心してそのまま使える形か

## How we use it (D-062)
Only improvements that facts in the repository (records, data, measurements) support. No effect that was not measured is added
to score points.
