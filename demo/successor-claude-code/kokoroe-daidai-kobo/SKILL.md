# 心得帳 — 株式会社だいだい工房

## 使い方
1. 相手の取引先のファイル（下の表）だけを読む。全社の作法はこのファイルの下にある。
2. 作法に従って答える。答えには、根拠の項目 ID と、沿革に書かれた「わけ」を添える。
3. 心得帳に書かれていないことは推測しない。「心得帳には記録がない。師匠（または前任者）に確認を」と答える。
4. 値引き・契約条件は自分で決めない。必ず人が判断する。
